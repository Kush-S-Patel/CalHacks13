# Hyphenate track alignment

Source: *Beyond Agentic Harnesses · Hyphenate CalHacks Workshop*

## The four questions

| Question | SwarmCFO answer |
| --- | --- |
| **WORLD** — Where does it act? | Work items over synced golden records (`sow/sync.py`, SpacetimeDB tables) |
| **TIME** — What does it remember next quarter? | Policies + precedents (`learn.py`, `improve.py`) |
| **TEAM** — Who does it work with? | Named actors + RBAC (`roles.py`); Maya + five agents + gateway |
| **LIMITS** — What may it do, and can it prove why? | `can()` + `transition()` + append-only audit |

## Strong vs weak (we aim strong)

- Real company, messy corner, **answer key** (`scenario.ANSWER_KEY`)
- Few roles done deep (cash, AP, AR, spend, runway)
- Asks at the right moment; **handles a no**
- Limits in code; record of every call
- Stage moment + **score** (`scoring.score_run`)
